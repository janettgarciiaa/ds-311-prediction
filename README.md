# Predicting Unresolved NYC 311 Complaints

## Overview
This project builds a machine learning model to predict whether NYC 311 service requests will remain unresolved. The goal is to identify patterns in complaint data that can help improve response prioritization and service efficiency.

## Problem
Not all 311 complaints are resolved in a timely manner. This project aims to predict which complaints are likely to remain unresolved based on historical data.

## Approach
- Data cleaning and preprocessing
- Feature engineering on complaint type, borough, and time-related variables
- Model training using Logistic Regression
- Evaluation using classification metrics

## Model
- Logistic Regression

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- Confusion Matrix

## Key Insight
The model identifies patterns in complaint types and other features that are associated with unresolved cases. This can help inform better allocation of resources and improve response times.
